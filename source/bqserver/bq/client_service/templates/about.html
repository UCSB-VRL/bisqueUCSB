Bio-Image Semantic Query User Environment

BisQue on GitHub

BisQue is an open-source platform for managing, exploring, and analyzing large-scale scientific multimodal data. BisQue combines images with structured metadata, annotations, sensor and experimental measurements, derived data products, models, workflows, and provenance. Its scalable web-services architecture supports data organization and search, interactive visualization, distributed storage, high-throughput analysis, and reproducible execution across diverse scientific domains.

BisQue now extends into BisQue Ultra, integrating large language model reasoning directly on top of the BisQue platform for more advanced, context-aware scientific analysis.

BisQue is developed by the Center for Multimodal Big Data Science and Healthcare at UC Santa Barbara — accelerating scientific discovery with multimodal AI. The project is a multi-institutional collaboration spanning UC Santa Barbara, UC Riverside, and the Smithsonian Institution, and the research built on top of BisQue spans four main areas: ecology, materials science, healthcare, and marine science.

What's next: BisQue Ultra

Our next generation of BisQue is BisQue Ultra — a scientific agentic AI workbench for data, models, and evidence. It brings rich agentic workflows to the platform: language is routed into tools, code, and models; long-running analyses are durable and recoverable; and every result — figures, tables, metrics, reports, and run events — stays attached to the same inspectable analysis record. Model operations are evidence-gated, so newer weights are promoted only when the declared evidence supports it.
